# Public roadmap

IntentGraphs Diagram-as-Code is a local-first, validated diagram workflow. This roadmap describes public
direction, not dated commitments. Detailed execution belongs in [GitHub Issues](https://github.com/IntentGraphs/diagram-as-code/issues)
and [GitHub Projects](https://github.com/IntentGraphs/diagram-as-code/projects), when those views are in use.

## Now

- Improve the public landing page and editor onboarding.
- Make the multi-diagram Workspace Tour the default fresh-session experience.
- Add a verified editor screenshot based on the current public UI.
- Keep Pages and the README playground path honest and verifiable.
- Remove stale references to deleted internal roadmap documents.

## Next

- Add professional showcase examples for BPMN, architecture, flowcharts, mind maps, and Gantt.
- Improve the zero-install CLI experience when public package publishing is ready.
- Expose validation and SARIF clearly for CI and AI-agent workflows.
- Add a short workflow demo showing generate → validate → repair → export.

## Later

- Narrow GitHub Action integration.
- Narrow MCP tools around capabilities, validation, rendering, exporting, importing, review, and generation.
- Shareable playground examples.
- VS Code integration.
- Stable public JavaScript APIs after the package boundary is ready.

## Not planned / explicit boundaries

- Hosted collaboration backend.
- Default telemetry.
- Continuous automatic text ↔ Diagram Editor synchronization.
- Full BPMN execution semantics.
- Claims of universal BPMN 2.0 support.
- Native editable Word-shape DOCX output unless it actually ships.
